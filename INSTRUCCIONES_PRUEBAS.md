# GOTYSHOP — Pruebas de Karma y Jasmine

Este proyecto conserva los archivos de interfaz del repositorio de tus compañeros. Se añadieron únicamente archivos de pruebas y configuración.

## Comandos (PowerShell)

1. `npm.cmd install` (actualiza también `package-lock.json` con las dependencias de pruebas)
2. `npm.cmd run dev` — ver la página React
3. `npm.cmd test` — generar el bundle, ejecutar 10 pruebas y medir cobertura
4. `start .\coverage\html\index.html` — abrir informe HTML

**Importante:** El ZIP conserva el `package-lock.json` original del equipo. Después de `npm.cmd install`, revisa y sube el lock actualizado junto a los cambios de dependencias. No copies el ZIP completo sobre una rama del equipo que tenga cambios posteriores: utiliza una rama y revisa el diff.

Archivos de código de interfaz (`src/App.jsx`, `src/components`, CSS, `public`, `src/data`) conservados sin modificaciones.
